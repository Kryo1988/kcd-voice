# KCD Voice

Das TeamSpeak-3-Plugin für den Rollenspielserver [Böhmische Chroniken](https://boehmische-chroniken.de) (Kingdom Come: Deliverance 2 mit KCD:MP).

Mit dem Plugin hörst du die anderen Spieler so, wie ihre Figuren im Spiel stehen: leiser mit dem Abstand, von links oder rechts, gedämpft hinter Wänden. Die aktuelle Fassung steht unter [Releases](https://github.com/Kryo1988/kcd-voice/releases/latest).

## Installieren

1. TeamSpeak 3 ganz schließen (auch rechts unten im Tray).
2. `KCD_Voice.ts3_plugin` herunterladen und doppelklicken, im Installer bestätigen.
3. TeamSpeak starten. Unter Extras → Optionen → Addons steht „KCD Voice“, unter Plugins → KCD Voice findest du die Einstellungen.

Hier liegt nur die fertige Datei, kein Quellcode.
